## T2: GapMapPage Subject Selector Bug

**Problem:** Current code extracts subjects from `topic_id` — but a subject has multiple topics. The selector should filter by subject, not topic.

**Fix in `GapMapPage.tsx`:**
- Subject selector should list unique subjects from the class's enrolled subjects
- Currently the `useClassGapMap` hook requires `subject_id` as a query param — but the page needs a subject list first
- The `/classes/{classId}/summary` endpoint doesn't return subjects either

**Alternative approach:**
- Add subject list from teacher's enrolled classes via existing `useTeacherDashboard` hook
- Use subject_id from class data to filter the gap map

**Required change:**
1. Get subjects from teacher's class list (already available via `useTeacherDashboard`)
2. Show subject tabs/dropdown correctly
3. Pass subject_id to `useClassGapMap`

Also: **class average row is NOT pinned at bottom** — the brief explicitly says "The class average row is pinned at the bottom." Current implementation has it as the last column, not a sticky row.
