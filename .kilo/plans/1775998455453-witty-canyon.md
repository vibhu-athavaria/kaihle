# Fix MyStudentsPage Hooks Violation

## Problem

`MyStudents.tsx` line 25-27 calls hooks inside a `.map()` loop:

```typescript
const classResults = classes.map((cls) =>
  useClassStudents(cls.id, cls.subjectId),
);
```

This violates React's Rules of Hooks - hooks must be called unconditionally at the top level, not inside loops. The hook count changes when `classes` array length changes between renders.

## Solution Approach

Extract a child component for each class that calls hooks at the top level. MyStudentsPage renders these child components conditionally.
