## Why This Blocks M1-2-T1

`cambridge_v1.json` seeds 193 subtopics with learning objectives directly into the
database. These objectives feed into AI-generated lesson plans. If a topic name is
wrong or a learning objective doesn't match the Cambridge syllabus, every lesson plan
generated for the pilot school will contain the error. Cambridge-certified teachers
will notice immediately and lose trust in the platform.

This review costs 4–6 hours now. Fixing it post-launch costs significantly more.

## What Vidhya Reviews

Open `backend/data/curriculum/curriculum_review.csv` (generated by M1-2-T3a).

For each row, check the following and fill in `review_ok` (Y/N) and
`correction_needed` (free text if N):

### 1. Subtopic name accuracy
Does the name match Cambridge's published syllabus terminology exactly?

- Cambridge Lower Secondary: syllabuses 0862 (Maths), 0893 (Science), 0851 (English)
- Cambridge IGCSE: 0580 (Maths), 0610 (Biology), 0620 (Chemistry), 0625 (Physics), 0500 (English), 0475 (Literature)

Common issues to watch for:
- "Force and Motion" vs Cambridge's exact term "Forces and Their Effects"
- "Statistics" vs Cambridge's "Statistics and Probability"
- Trigonometry appearing in Grade 6–8 rows (it should only appear in Grades 9–10)
- ENGL rows containing English Language content (ENGL is Literature only)

### 2. Learning objective alignment
Does the `learning_objective` text reflect what Cambridge actually requires at that
stage? The level of specificity matters:

- Too vague: "Understand gravity" → should be "Describe gravity as a non-contact force
  that attracts masses; understand the difference between mass and weight"
- Too advanced: an objective that belongs to IGCSE appearing in a Grade 6 row
- Wrong strand: a physics objective in an SCI row labelled with a biology topic

### 3. Prerequisite logic (spot-check 20% minimum)
Does the prerequisite chain make educational sense? Check at least:
- All Algebra subtopics in Maths (prerequisite chains are most complex here)
- All Organic Chemistry subtopics in CHEM
- Cell Biology → Photosynthesis chain in BIO

Example of a logical chain:
- "Expanding Brackets" must appear as a prerequisite of "Factoring Quadratics"
- "Cell Structure" must appear as a prerequisite of "Photosynthesis"

### 4. Difficulty range sanity (spot-check)
Are the `difficulty_min` and `difficulty_max` values plausible?
- Grade 6 subtopics: expected range roughly 1.0–2.5
- Grade 10 IGCSE Physics: expected range roughly 3.5–5.0
- Flag any Grade 6 row with difficulty > 3.5 or any Grade 10 row with difficulty < 2.0

### Priority areas most likely to have issues:
- **SCI (Integrated Science):** topics are unified across biology/chemistry/physics strands — verify names work for a combined course
- **ENG vs ENGL:** completely different syllabuses, must not have mixed content
- **IGCSE Maths:** algebra naming conventions differ from Lower Secondary
- **IGCSE Biology/Chemistry/Physics:** most complex syllabuses, most likely to have vague objectives

## What Vibhu Does After Vidhya Completes the Review

1. Collect Vidhya's completed CSV (all `review_ok` values filled, corrections noted)
2. For each row where `review_ok = N`, apply the correction to `cambridge_v1.json`

Common correction types:

```json
// Name correction
{ "name": "Force and Motion" }
→ { "name": "Forces and Their Effects" }

// Learning objective improvement
{ "learning_objective": "Understand gravity" }
→ { "learning_objective": "Describe gravity as a non-contact force; distinguish between mass (kg) and weight (N)." }

// Adding missing prerequisite
{ "prerequisites": [] }
→ { "prerequisites": ["MATH-ALG-G8-03", "MATH-ALG-G8-04"] }
```

3. Update the `_meta` block in `cambridge_v1.json`:

```json
"_meta": {
  "version": "1.1",
  "authored_by": "Vibhu Athavaria",
  "reviewed_by": "Vidhya",
  "review_date": "2026-[MM-DD]",
  "review_status": "approved",
  "corrections_applied": [N]
}
```

4. Verify the JSON is still valid:
```bash
python -m json.tool backend/data/curriculum/cambridge_v1.json > /dev/null && echo "Valid JSON"
```

5. Commit with message:
```
chore(curriculum): apply Vidhya review corrections to cambridge_v1.json

M1-2-T3b complete — N corrections applied across [subjects].
review_status: approved. Unblocks M1-2-T1.
```
