## Acceptance Criteria

- `GET /api/v1/classes/{id}/lesson-plans` with teacher JWT returns `200` with `{ data: [], total: 0, page: 1, page_size: 10 }`
- `GET /api/v1/classes/{id}/lesson-plans` with student JWT returns `403`
- `GET /api/v1/lesson-plans/{id}` with teacher JWT returns `404` (not 500)
- `PATCH /api/v1/lesson-plans/{id}` with teacher JWT returns `404` (not 500)
- `POST /api/v1/lesson-plans/{id}/regenerate` with teacher JWT returns `404` (not 500)
- `PATCH /api/v1/lesson-plans/{id}/status` with teacher JWT returns `404` (not 500)
- All routes appear in `/docs` under the `lesson-plans` tag
- `mypy app/api/v1/routes/lesson_plans.py` passes
